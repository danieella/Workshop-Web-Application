# "Choose Your Own Adventure" Website Project!

This is a beginner-friendly website project where you can create a **Choose your Adventure** story using HTML/CSS.

You will get to learn all the main basics of HTML and write a story that involves clickable features and fun activities!

## What You'll Build
- A story with many pathways and endings
- Clickable choices using links
- A webpage that readers can explore in different ways

## What Can You Change?
- Rewrite the story
- Add more choices/endings
- Add images
- Change colors and fonts using CSS

Most of all I encourage you to make it your own!

## What You'll Learn
- The structure of HTML Pages
- How the website connects content together
- Customizing through CSS
- How Javascript creates a more interactive page
